# Telegram-бот для скачивания видео

Простой рабочий MVP: отправьте боту ссылку на YouTube, и он попробует скачать видео и прислать его в ответ. Бот написан на Python с библиотекой `aiogram`.

## Что умеет бот

- Принимает ссылки на YouTube (`youtube.com` и `youtu.be`).
- Скачивает лучшее доступное качество до 1080p с помощью `yt-dlp`.
- При необходимости преобразует видео в совместимый MP4 через FFmpeg.
- Если видео не помещается в лимит Telegram, сжимает его, сохраняя разрешение.
- Удаляет временные файлы после обработки видео.

Для обработки актуальных YouTube-видео `yt-dlp` использует Node.js и пакет `yt-dlp-ejs`. Python-пакеты, включая `aiogram`, `yt-dlp` и `yt-dlp-ejs`, устанавливаются из `requirements.txt`.

## Что понадобится

- macOS и Python 3.
- Homebrew для установки Node.js и FFmpeg.
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather).

## Установка и запуск на macOS

1. Установите Homebrew, если он ещё не установлен: [brew.sh](https://brew.sh/).

2. Установите Python, Node.js и FFmpeg:

   ```bash
   brew install python node ffmpeg
   ```

3. Склонируйте проект и перейдите в его папку:

   ```bash
   git clone https://github.com/kr3ta/telegram-video-bot.git
   cd telegram-video-bot
   ```

4. Создайте и включите виртуальное окружение Python:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

5. Установите зависимости проекта:

   ```bash
   python -m pip install -r requirements.txt
   ```

6. Создайте в корне проекта файл `.env` и добавьте в него токен:

   ```env
   BOT_TOKEN=вставьте_сюда_токен_от_BotFather
   ```

   Не отправляйте и не публикуйте настоящий токен. Файл `.env` не нужно добавлять в Git.

7. Запустите бота:

   ```bash
   python bot.py
   ```

Оставьте терминал открытым, пока бот работает. Чтобы остановить его, нажмите `Ctrl+C`.

## Известные ограничения

- Сейчас поддерживается только YouTube. TikTok и VK ещё не добавлены.
- Максимальное исходное качество — 1080p. Если файл превышает 48 MB, FFmpeg снижает битрейт, не меняя разрешение.
- При сильном сжатии качество изображения может стать ниже. Обычный Bot API Telegram принимает файлы до 50 MB.
- Если скачивание или отправка не удались, бот отвечает коротким сообщением, а подробная причина остаётся в терминале.
- Бот работает локально на компьютере. Настройка VPS, Docker и постоянной работы на сервере пока не сделана.

Это ранняя версия проекта; возможности и инструкции могут меняться.
