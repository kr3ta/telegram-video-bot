# Telegram Video Downloader Bot

Простой MVP Telegram-бота для скачивания видео с YouTube. Бот принимает ссылку на YouTube или `youtu.be`, скачивает видео с помощью `yt-dlp` и отправляет MP4 обратно в чат.

## Что умеет

- Принимать ссылки на YouTube.
- Скачивать видео через `yt-dlp`.
- Отправлять готовый MP4 в Telegram.

## Что понадобится

- Python.
- Node.js — используется `yt-dlp` для обработки JavaScript-проверок YouTube.
- `yt-dlp`, доступный из командной строки.
- FFmpeg — нужен `yt-dlp` для обработки и объединения медиапотоков.
- Токен Telegram-бота.

## Установка и запуск

1. Склонируйте репозиторий и перейдите в его каталог:

   ```bash
   git clone https://github.com/kr3ta/telegram-video-bot.git
   cd telegram-video-bot
   ```

2. Установите Python-зависимости:

   ```bash
   python -m pip install aiogram python-dotenv
   ```

3. Создайте в корне проекта файл `.env` и добавьте токен бота:

   ```env
   BOT_TOKEN=PASTE_YOUR_TELEGRAM_BOT_TOKEN_HERE
   ```

   Не публикуйте настоящий токен. Файл `.env` уже исключён из Git.

4. Запустите бота:

   ```bash
   python bot.py
   ```

## Ограничения MVP

- Поддерживаются только ссылки на YouTube.
- Выбор формата видео задан в коде и пока не настраивается пользователем.
- Обработка ошибок и одновременных запросов пока базовая.
- Скачанные файлы автоматически не удаляются.

Это ранняя рабочая версия проекта; настройки и поведение бота могут измениться.
